# Hgzen

红果漫剧（`com.kylin.read`）的 LSPosed 模块：去广告、会员解锁、界面精简与播放体验优化。

## 功能
- 会员解锁、去广告、VIP 图标
- 1080P / 最高画质
- 倍速播放（支持长按临时加速及释放恢复）
- 界面精简：隐藏状态栏、播放控件、选集、进度条、福利入口挂件等
- 恢复暂停、双击弹幕、禁用刷新等

## 目标应用
- 红果漫剧 `7.4.3.32`（versionCode `74332`）

## 反馈
- https://t.me/xiyouF4

## 安装
1. 手机需 root + LSPosed。
2. 安装本模块 APK。
3. LSPosed → 模块 → 启用 Hgzen → 作用域勾选 `com.kylin.read`。
4. 重启目标 App。
