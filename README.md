# Hgzen

面向红果免费漫剧和红果免费短剧的 LSPosed 模块，提供界面精简与播放体验优化。两款应用使用独立适配和配置，同一个模块 APK 可用于两个作用域。

## 适配版本

| 应用 | 包名 | 推荐版本（versionName） | 版本号（versionCode） |
|---|---|---|---|
| 红果免费漫剧 | `com.kylin.read` | `7.4.3.32` | `74332` |
| 红果免费短剧 | `com.phoenix.read` | `7.3.1.32` | `73132` |

以上为当前针对性适配版本，不代表所有功能均已完整验收。其他版本未验证；涉及混淆类名、资源 ID 的功能可能不生效，不建议仅按应用名称判断兼容性。

## 主要功能与说明

- 播放倍速与长按临时加速适配。
- 视频界面精简：右侧互动、作品信息、全屏按钮及其他独立隐藏项。
- “我的-顶部导航”：针对个人页金币、订单、消息等整排快捷入口，独立于播放控件总开关；不是视频页顶部频道栏。
- 短剧双击评论：隐藏右侧互动后，仍可双击视频进入评论；推荐页场景已实测，其他播放页面仍需验证。
- 短剧推荐页广告与直播卡过滤：推荐流广告、顶部广告与直播卡在推荐页不展示；不影响剧集内内容与激励广告。
- 打开应用跳转至：冷启动后自动进入「剧集」或「我的」，可选，默认保持应用默认页。
- VIP 图标为本地显示装饰，不代表真实会员资格。
- 广告处理、全部倍速组合、隐藏项关闭恢复等功能的验证范围，以对应版本 Release 说明为准。
- 漫剧和短剧不共用混淆映射；不能将一款应用的验证结果视为另一款也已验证。

## 安装使用

1. 手机需已配置 root 和 LSPosed。
2. 从 Releases 下载并安装模块 APK。
3. 在 LSPosed 中启用 Hgzen，按实际使用情况勾选 `com.kylin.read`、`com.phoenix.read` 作用域。
4. 完全退出并重新打开目标 App，无需重启手机。
5. 在目标 App 内同时按音量加、音量减，或通过软件设置页右侧的 Hgzen 图标打开模块设置。
